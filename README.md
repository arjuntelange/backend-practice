# Backend Practice

This repository is my hands-on workspace for learning backend development. It keeps practice for different backend technologies together, while each topic has its own folder.

## Topics

| Folder | Focus |
| --- | --- |
| [`nodejs-practice/`](./nodejs-practice/) | Node.js fundamentals and small exercises |
| [`mysql-practice/`](./mysql-practice/) | SQL and relational database practice with MySQL |
| `express-practice/` | Express.js APIs and middleware (add when I begin) |
| `mongodb-practice/` | MongoDB and document database exercises (add when I begin) |

## How I practice

- Keep examples and notes in the folder for the technology they cover.
- Use numbered file or lesson names when a clear learning order helps.
- Build small exercises and projects as I learn; record useful commands and setup notes in that folder's README.
- Keep secrets, local configuration, and generated dependencies out of Git.

## Getting started

Open the folder for the topic I'm studying and read its README. For MySQL, I can write SQL in `.sql` files here and run them in MySQL Workbench, or use the MySQL command-line client. The SQL files are the saved practice; Workbench or the CLI is where I execute them against my local MySQL server.
