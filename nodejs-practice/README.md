# Node.js Practice

This folder contains my hands-on Node.js learning exercises, notes, and small projects. I work through the topics in small examples and keep each example with the subject it demonstrates.

## Topics

- CommonJS and ES modules
- Readline and command-line input
- File system (`fs`), paths, and operating system information
- Streams and events
- Networking and HTTP
- Cryptography and clustering
- Small practice projects

## Folder guide

The numbered topic folders indicate a suggested order. Some folders may contain several examples; read their local notes or source files to see what each one practices.

```text
nodejs-practice/
├── 01-commonjs/
├── 02-es-modules/
├── 03-readline/
├── 04-fs/
├── 05-path/
├── 06-streams/
├── 07-networking/
├── 08-http/
├── 09-events/
├── 10-cryptography/
├── 11-cluster/
└── README.md
```

Folder names reflect the current exercises and can evolve as I learn. To run an example, open its folder and follow any instructions there; otherwise run the relevant JavaScript file with Node.js from that folder.

## Learning approach

Read the example, run it, change it, and try a similar task without looking at the original. Keep this folder focused on Node.js practice; other backend topics live beside it in the parent `backend-practice` repository.
